# Face Recognition Project
A Python-based face recognition project using NumPy, SciPy, OpenCV and Artificial Neural Network.

## Technologies Used
- Python
- NumPy
- SciPy
- OpenCV
- Artificial Neural Network

## Files
- train.py - Model training
- recognize.py - Face recognition
- graph.py - Accuracy graph
- accuracy_graph.jpg - Accuracy graph
- accuracy_results.txt - Accuracy results
